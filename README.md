# HTB CPTS — Penetration Testing Study Notes

A structured knowledge base for studying the Hack The Box Certified Penetration Tester (CPTS) learning path.

This repository organizes module notes, short answers, detailed explanations, technical references, commands, and authorized lab observations to support learning and revision.

## Objectives

- Understand penetration testing concepts from fundamentals to advanced topics.
- Document module questions with concise answers and detailed explanations.
- Understand commands, options, and their practical applications.
- Maintain notes from authorized lab exercises.
- Record important findings, limitations, and lessons learned.
- Track study progress and build a professional technical portfolio.

## Standard Question Format

Each question will contain, as applicable:

1. Question or learning objective
2. Short answer
3. Detailed explanation
4. Technical background
5. Commands and option explanations
6. Practical lab notes
7. Key takeaways
8. Revision notes
9. References

## Practical Lab Documentation

Lab notes will distinguish between:

- **Observed:** Directly confirmed in an authorized lab.
- **Expected:** A result described by documentation or an exercise.
- **Inferred:** An interpretation supported by available evidence.
- **Unconfirmed:** A hypothesis requiring additional testing.

Commands and results will be documented accurately. No fabricated lab observations will be presented as evidence.
